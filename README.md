# maot1114.github.io-
Mid-Term Project: Digital Identity Portfolio
Project Overview
Create a personal website that showcases your digital identity using only HTML and CSS. This project is an opportunity to explore how you represent yourself online, emphasizing meaningful content and thoughtful design.

Technical Requirements
Technologies: Vanilla HTML and CSS only (no JavaScript, no frameworks)
Hosting: Publish the site on GitHub Pages
Navigation: Include a navigation bar with links to at least:
3 distinct pages OR
3 distinct sections of a single-page site
Content Guidelines
Your site should include:

A clear representation of your personal or professional identity
Semantic HTML markup
Responsive design that looks good on a mobile sized screen (~450px) and desktop sized screen (~1200px)
Accessible design principles
Prohibited Content
Do NOT include personal contact information like phone numbers (email is fine)
Avoid sharing other sensitive personal details
Reflection (250 words minimum)
Submit a written reflection addressing the following prompts:

Design Philosophy and Identity Representation (~ 100 words)

How did you intentionally use design elements (color, typography, layout) to represent your personal or professional identity?
Discuss the deliberate choices you made in visual communication and how these choices reflect your understanding of personal branding through web design.
Explain how your design goes beyond aesthetic preferences to communicate something meaningful about who you are.
Technical and Accessibility Considerations (~ 75 words)

Describe the challenges you encountered in creating a responsive design using only HTML and CSS.
Explain specific techniques you used to ensure your site is accessible and works across different devices and screen sizes.
Reflect on how technical constraints influenced your creative decisions.
Critical Perspective on Digital Identity (~ 75 words)

How does your website challenge or conform to traditional expectations of online personal representation?
Discuss the ethical considerations you thought about while designing a public-facing personal website.
Reflect on what it means to construct and present a digital version of yourself.
Reflection Guidelines:

Minimum 250 words total
Be specific and analytical
Connect your design choices to broader concepts of digital identity and web design principles
Proofread for clarity and depth of insight
Evaluation Criteria
Semantic HTML structure (20%)
Responsive CSS layout (40%)
Visual design and creativity (15%)
Accessibility (10%)
Reflection quality (15%)
Submission
Multiple submissions are fine. Do not submit a single PDF with reflection and link in it.

Live site URL on GitHub Pages
Reflection document as a PDF
Reflection must be submitted as a single PDF file
Include your name on the document
Ensure the document meets the 250-word minimum requirement
